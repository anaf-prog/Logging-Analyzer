📝 Contoh Format Response XML
💡 Cara Penggunaan:
  • Gunakan ${namaVariable} sebagai placeholder
  • XML harus memiliki root element (satu tag pembungkus utama)
  • Bisa tambahkan <?xml version="1.0" encoding="UTF-8"?> di awal
  • Value bisa berupa string atau nested XML
📌 Contoh 1: Response XML Sederhana
                        <?xml version="1.0" encoding="UTF-8"?>
                        <response>
                            <statusCode>${statusCode}</statusCode>
                            <message>${message}</message>
                            <timestamp>${timestamp}</timestamp>
                            <success>${success}</success>
                        </response>
📌 Contoh 2: Response XML dengan Nested Data
                        <?xml version="1.0" encoding="UTF-8"?>
                        <response>
                            <statusCode>${statusCode}</statusCode>
                            <message>${message}</message>
                            <data>
                                <userId>${userId}</userId>
                                <username>${username}</username>
                                <email>${email}</email>
                                <phoneNumber>${phoneNumber}</phoneNumber>
                                <role>${role}</role>
                                <status>${status}</status>
                                <createdAt>${createdAt}</createdAt>
                            </data>
                        </response>
📌 Contoh 3: Response XML dengan Array (perulangan)
                        <?xml version="1.0" encoding="UTF-8"?>
                        <response>
                            <statusCode>${statusCode}</statusCode>
                            <message>${message}</message>
                            <data>
                                <users>
                                    <user>
                                        <userId>${users[0].userId}</userId>
                                        <username>${users[0].username}</username>
                                    </user>
                                    <user>
                                        <userId>${users[1].userId}</userId>
                                        <username>${users[1].username}</username>
                                    </user>
                                </users>
                                <total>${total}</total>
                            </data>
                        </response>
💡 Tips untuk Array di XML:

Untuk data array, lebih mudah menggunakan format JSON. Tapi jika tetap ingin XML, Anda bisa:
1. Generate manual dengan placeholder per index seperti contoh di atas
2. Atau kirim data sebagai JSON string di dalam CDATA: <![CDATA[${users}]]>

⚠️ Catatan Penting:
  • Pastikan XML valid (setiap tag pembuka harus ada penutupnya)
  • Gunakan &lt; untuk < dan &gt; untuk > jika perlu
  • Gunakan tombol "Test Template" untuk mencoba sebelum disimpan
