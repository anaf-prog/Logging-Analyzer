📝 Contoh Format Response JSON
💡 Cara Penggunaan:
  • Gunakan ${namaVariable} sebagai placeholder
  • String pakai tanda kutip: "${username}"
  • Number/Boolean TANPA tanda kutip: ${userId} atau ${isActive}
  • Array/List bisa langsung: ${users}
  • Nested object: "user": ${user} atau ${data.user.id}
📌 Contoh 1: Response Sederhana
                        {
                            "statusCode": ${statusCode},
                            "message": "${message}",
                            "timestamp": "${timestamp}",
                            "success": ${success}
                        }
📌 Contoh 2: Response dengan Nested Object
                        {
                            "statusCode": ${statusCode},
                            "message": "${message}",
                            "data": {
                                "userId": ${userId},
                                "username": "${username}",
                                "email": "${email}",
                                "phoneNumber": "${phoneNumber}",
                                "role": "${role}",
                                "status": "${status}",
                                "createdAt": "${createdAt}"
                            }
                        }
📌 Contoh 3: Response dengan Array
                        {
                            "statusCode": ${statusCode},
                            "message": "${message}",
                            "data": {
                                "users": ${users},
                                "total": ${total},
                                "page": ${page}
                            }
                        }
⚠️ Catatan Penting:
  • Pastikan JSON valid (tidak ada koma berlebih di akhir)
  • Placeholder akan diganti dengan data real dari sistem
  • Gunakan tombol "Test Template" untuk mencoba sebelum disimpan
